These three invoice images are generated test documents with fictional values/identifiers. They are not real tax invoices and not valid evidence of GST registration. Expected fields and source text are in manifest.json.

Run the evaluation commands in docs/OCR_EVALUATION.md. Keep customer invoices and raw confidential OCR output out of this folder and Git. The source-package script includes these small committed images for reproducible evaluation.
